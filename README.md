# Controle de Vendas Android

Aplicativo acadêmico desenvolvido para a disciplina Programação para Dispositivos Móveis em Android.

## Objetivo

Auxiliar pequenos estabelecimentos no controle de vendas e estoque através de uma aplicação Android simples e intuitiva.

## Funcionalidades

- Cadastro de produtos
- Controle de estoque
- Registro de vendas
- Consulta de produtos cadastrados

## Tecnologias

- Kotlin
- Android Studio
- Android SDK
